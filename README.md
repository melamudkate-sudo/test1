# DEMIAND — цифровой аэрогриль

Готовый статический сайт для GitHub Pages. Без сборки, npm, сервера приложений, ключей и сторонних JS-библиотек. Шрифты и изображения локальные. Ничего не опубликовано в Sites или GitHub.

## Запуск локально

Из этой папки:

```sh
python3 -m http.server 5100 --bind 127.0.0.1
```

Открыть http://127.0.0.1:5100/. Для копирования используйте localhost или HTTPS, а не открытие index.html двойным кликом. Если буфер обмена запрещён браузером, сайт предложит ручное копирование.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите **содержимое этой папки в корень**: index.html должен лежать сразу в репозитории. Включите скрытый файл .nojekyll.
2. В репозитории откройте Settings → Pages.
3. В Source выберите Deploy from a branch, затем ветку main и /(root), нажмите Save.
4. Дождитесь успешной публикации. GitHub покажет адрес вида `https://USERNAME.github.io/REPOSITORY/`.
5. В config.js замените `shareUrl` на `https://USERNAME.github.io/REPOSITORY/digital-airfryer/` и сохраните изменение в репозитории.
6. Проверьте обе страницы и копируемый текст по HTTPS. Не теряйте часть `/REPOSITORY/` в ссылке.

Ссылки на изображения, шрифты и вторую страницу относительные, поэтому сайт работает и в подпапке GitHub Pages.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Основные файлы

- `index.html` — основной визуальный лендинг
- `digital-airfryer/index.html` — визуальная страница аэрогриля со скрытым HTML-промптом
- `digital-airfryer/prompt.txt` — текстовая копия промпта для редактирования/прямого чтения, не выводится в интерфейсе
- `config.js` — ссылка магазина, копируемая фраза, видео и изображения
- `styles.css` — адаптивный дизайн и анимации
- `app.js` — копирование, переходы, анимации, управление видео
- `assets/` — логотипы, фотографии, шрифты и лицензии
- `MEDIA-BRIEF.md` — список необходимых материалов, размеры и сценарий
- `MECHANICS.md` — схема двух лендингов и ограничения скрытого промпта

## Где что менять

В `config.js`:

- `storeUrl`: уже `https://demiand.ru/`
- `shareUrl`: `https://demiand-ai-experience.ru/digital-airfryer/`
- `shareText`: «Кажется, ты поторопился с подачей. Доведи мысль до готовности с DEMIAND: {url}»
- `videoUrl`: путь к готовому ролику, например `assets/demiand-film.mp4`
- `videoPoster`: необязательный постер, например `assets/video-poster.webp`
- `videoCaptions`: необязательный файл WebVTT
- `heroImage`: замена изображения главного экрана; путь относительно корня проекта
- `digitalImage`: замена изображения на второй странице; путь относительно корня проекта

Видео — 16:9, во всю ширину окна. Запускается без звука при попадании в область просмотра, зацикливается, останавливается за пределами экрана и при уходе на другую вкладку. Управляющие элементы не отображаются. Пока videoUrl пуст, виден спокойный кадр-заглушка. На отдельных устройствах режим энергосбережения или настройки браузера могут запретить автозапуск: без кнопки воспроизведения там останется постер.

Анимации учитывают prefers-reduced-motion. Отдельных кнопок паузы в интерфейсе нет по запросу заказчика. Переход между документами использует View Transitions в поддерживающих браузерах и короткое затухание в остальных.

## Фирменный стиль и исходники

Шрифты Montserrat и Exo 2, цвета #ef001b, #121318 и светлые нейтральные взяты из CSS demiand.partners. Композиция самостоятельная. Логотип и исходное фото 5100 предоставлены заказчиком. Исходный PNG сохранён как `assets/5100-black.png`. Копия без фона `assets/5100-cutout.png` подготовлена через встроенный imagegen для прототипа; перед публикацией проверьте точность мелких деталей изделия. Лицензии шрифтов — в `assets/fonts/`.

## Актуальная визуальная версия — 8 октября 2026

Чёрный фон, холодный голубой код, тёплые искры и угольки, короткий глитч. Нарисованных языков пламени и анимированного диалога нет. Кнопки копирования и магазина оформлены в едином стиле. Подробности — DESIGN-NOTES.md.

Шапка закреплена. Первый экран вместе с шапкой занимает 100svh. На телефоне кнопка под продуктом. Инструкция расположена перед горизонтальным видеоблоком.

Главный визуал подготовлен под 3:4, 1080 × 1440 px, на ровном чёрном фоне #000000. Подключён новый квадратный MP4 на чёрном фоне: assets/5100-code-close.mp4, около 2 МБ. Он вписывается без обрезки. Присланный 8 октября стилевой референс на сайт не установлен.

Настройки: heroVideo и heroVideoPoster. Для перехода на статичную картинку очистить heroVideo и указать heroImage. Старые прозрачные видео остаются в assets, но не загружаются. Актуальные размеры и список материалов — MEDIA-BRIEF.md.

Обновление: поля нового видео подрезаны до 900 × 900 px, аэрогриль крупнее на 20% при том же размере блока. Постер: assets/5100-code-close-poster.webp. Контурная типографика возвращена в слово «ответ?» и номера шагов; кнопки прозрачные с тонкой рамкой. Искры находятся над видео.
