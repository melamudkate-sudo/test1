# Метаданные и превью ссылок

Публичный адрес: https://demiand-ai-experience.ru/

- Главная вкладка: «Дожарь ИИ — DEMIAND».
- Вторая вкладка: «Цифровой DEMIAND».
- Уникальные description и canonical для обеих страниц.
- Open Graph: website, ru_RU, заголовок, описание, постоянный URL, JPEG 1200 × 630 с alt и размерами.
- Twitter Cards: summary_large_image, заголовок, описание, тот же JPEG и alt. Аккаунт Twitter не выдумывался.
- assets/social-preview.jpg — 1200 × 630, около 175 КБ.
- Favicon: короткий фирменный логотип из «Белый_сокращенный.png», белый знак с красным акцентом на чёрном фоне. SVG + ICO 16/32/48 + PNG 48 + Apple 180. Версия URL предотвращает использование старой иконки из кэша.
- robots.txt разрешает обход; sitemap.xml содержит главную страницу.
- Главная индексируется. Вторая страница с техническим промптом имеет noindex, follow: её HTML доступен для чтения, но она не предназначена для отдельной поисковой выдачи. Социальное превью у неё настроено.
- На главной JSON-LD WebSite с реальным брендом без выдуманных рейтингов и цен.

Метатеги записаны прямо в HTML. Основные тела страниц сохранены; по отдельной просьбе убраны ссылки навигации и мобильное меню. Копируемая фраза сохранена, ссылка-заглушка заменена на https://demiand-ai-experience.ru/digital-airfryer/.

Проверено: уникальность метатегов, существование локальных ресурсов, размер JPEG, формат ICO, XML sitemap, JSON-LD, DOM браузера и короткий title. Функционал копирования и промпт сохранены.

## Публикация

Сайт пока локальный. Чтобы карточки заработали при отправке ссылок, домен должен обслуживать эту папку по HTTPS; изображение /assets/social-preview.jpg должно быть доступно публично без авторизации. DNS и хостинг этим изменением не настраивались. На GitHub Pages нужно подключить указанный домен в Settings → Pages и настроить DNS.

После публикации проверить обе страницы и изображение по публичному адресу. Поисковики и мессенджеры могут кэшировать данные и самостоятельно менять заголовок/описание. Живое отображение в их выдаче локально не проверяется.
